安装与配置

  1. 在装有 dsh 的机器上，用上方命令安装插件（--ignore-scripts 不执行包内脚本）。
  2. 启动 DSH Web：dsh web --port 3080（或你现有的 Web Profile）。
  3. 进入 插件 → @astron-team/skillhub-dsh → SkillHub 设置 → 技能来源，把地址填为 —，点击「测试连接」后保存。此后技能搜索、下载、安装全部走内网实例，无需公网。

插件 tarball 的 sha256 由 publish-plugin.sh verify 维护；客户端可用 sha256sum <file> 或 certutil -hashfile <file> SHA256 核对后再安装。
